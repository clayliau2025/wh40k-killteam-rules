毀滅打擊 40KDevastating Wounds
攻擊受傷擲骰擲出未修正的 6（爆擊受傷）時，防守方無法進行常規護甲豁免或特殊豁免（特保），直接造成等於該武器傷害值的致命傷害！
重擊 40KLethal Hits
攻擊命中擲骰擲出未修正的 6（爆擊命中）時，該攻擊自動成功受傷，跳過受傷骰判定直接進入防守方豁免擲骰階段。
連續命中 x 40KSustained Hits x
攻擊命中擲骰擲出未修正的 6（爆擊命中）時，本次命中除了保留之外，額外追加產生 x 次額外命中判定！
激流 / 噴射 40KTorrent
本武器在射程內射擊時自動命中目標，完全無須進行命中擲骰 (Hit Roll)，直接擲骰決定攻擊次數並進行受傷判定。
急速射擊 x 40KRapid Fire x
當目標處於武器最大射程的一半（半程）以內時，每次攻擊的攻擊次數 (Attacks) 額外增加 x 次。
劈砍 x 40KCleave x
第 11 版新規則特規。近戰攻擊爆擊命中或高力打擊時，武器的穿甲值 (AP) 額外改善 x 點（例如 AP -2 變為 AP -3）。
衝擊破防 40KLance
持此武器的單位在發動過衝鋒 (Charge) 的回合內發動近戰攻擊時，近戰武器的受傷骰 (Wound roll) +1。
雙聯武器 40KTwin-linked
使用本武器進行攻擊時，可以重新擲出該次攻擊所有失敗的受傷骰 (Re-roll Wound rolls)。
精確打擊 40KPrecision
若攻擊目標為聯合單位（有角色附屬帶隊），攻擊者可以將成功的攻擊傷害直接分配給敵方角色 (Character) 模型，繞過普通護衛兵！
熱熔 x 40KMelta x
當目標處於武器最大射程的一半（半程）以內時，每次未被存救的成功攻擊其傷害值額外增加 x 點（如熱熔 2 增加 2 點傷害）。
危險武器 40KHazardous
射擊結束後為每件危險武器擲 1 顆 D6。每擲出 1，射手單位必須消滅 1 名裝備此武器的模型（若為角色/載具則承受 3 點致命傷害）。
精準 xAccurate x
你可以在不擲骰子的情況下，將最多 x 顆攻擊骰直接作為「普通成功」保留。若持有多個精準 x，可視為精準 2。
平衡Balanced
發動攻擊擲攻擊骰後，你可以重擲其中的 1 顆攻擊骰。
爆破 xBlast x
射擊主目標後，對距離主目標 x 吋以內且對其可見的所有次要目標依序單獨結算射擊（範圍內所有特工皆屬有效目標，無視隱蔽指令）。
殘暴Brutal
在近戰搏鬥中，你的對手只能使用「爆擊成功」進行招架，無法使用普通成功招架你的任何打擊。
不息Ceaseless
攻擊擲骰後，你可以挑選一個點數結果（例如所有 2 點），並重擲所有該點數的攻擊骰。
毀滅 xDevastating x
你每次保留 1 次爆擊成功時，立即對目標造成 x 點直接傷害。此爆擊骰後續仍可正常進行打擊結算。
重型Heavy
特工不能在進行過移動的啟動或反制中使用此武器，使用此武器後亦不能再執行任何移動。若標注「重型(僅限衝刺)」，則僅允許執行衝刺。
過熱Hot
使用本武器後擲 1 顆 D6。若點數小於武器的 Hit 命中值，射手自身受到相當於該點數 × 2 的傷害。單次行動多次射擊僅需擲骰一次。
致命 x+Lethal x+
點數大於或等於 x 的成功骰直接視為「爆擊成功」（例如致命 5+ 代表 5 與 6 均為爆擊）。
受限 xLimited x
特工在一場戰鬥中累計使用本武器達到 x 次後，便耗盡彈藥，無法再次使用本武器。
穿刺 x / 爆擊穿刺 xPiercing x
防禦方擲出的防禦骰數量直接減少 x 顆（例如穿刺 1 減少 1 顆）。若是「爆擊穿刺 x」，則唯有你保留了爆擊成功時才會觸發此扣骰效果。
痛擊Punishing
若你在攻擊擲骰中保留了任何爆擊成功，你可以將 1 顆原本失敗的攻擊骰轉為「普通成功」保留。
射程 xRange x
距離限制武器。只有在活躍特工 x 吋距離內的敵方特工才能被選為有效射擊目標（例如射程 8"）。
無情Relentless
攻擊擲骰後，你可以重擲該次攻擊骰中的任意數量骰子。
撕裂Rending
若你保留了任何爆擊成功，你可以將另 1 顆「普通成功」升級為「爆擊成功」保留。
飽和Saturate
防禦方無法獲得掩護帶來的免費保留防禦成功（防禦方必須正常擲出所有防禦骰）。
追蹤 / 追蹤輕型Seek
選擇有效目標時，持有隱蔽指令的特工無法藉由地形獲得掩護判定。「追蹤輕型」則僅限無法透過輕型掩體獲得掩護。
重創Severe
若你本次攻擊擲骰中沒有保留任何爆擊成功，你可以將 1 次普通成功替換為爆擊成功。此替換可正常觸發爆擊穿刺或毀滅效果。
震盪Shock
在近戰中你首次使用爆擊成功進行打擊時，額外棄置對手 1 顆尚未結算的普通成功（若對手無普通成功則棄置其爆擊成功）。
靜音Silent
特工在持有「隱蔽指令」的狀態下，依然可以使用本武器正常宣告並執行射擊行動。
暈眩Stun
若你保留了任何爆擊成功，被本武器攻擊的特工其 APL（行動點上限）屬性立即減少 1 點，直到目標的下一次啟動結束為止。
洪流 xTorrent x
選定主要目標後，可同時選擇距離主要目標 x 吋內、且不在友軍控制範圍內的任意數量其他可見特工為次要目標，依序對所有目標分別進行單獨射擊。

英文原名 (English) 繁體中文標準 (Traditional Chinese) 說明與遊戲內涵意
Operative 特工 殺戮小隊戰場上的單個微縮模型作戰單位。
Activation 啟動 輪流指派一名特工執行指令選定與行動花費的完整流程。
Initiative 先攻權 戰略階段各擲 D6 決定，勝者優先選擇或執行戰略計謀與特工啟動順位。
Turning Point 轉折點 對戰局數計算單位（標準一場戰鬥共計 4 個轉折點）。
Firefight Phase 交戰階段 特工輪流啟動並執行移動、射擊與肉搏搏鬥的核心戰鬥階段。
Strategy Phase 戰略階段 轉折點開端，雙方獲取CP、就緒特工與輪流打出戰略策略的階段。
Reposition 換位 (1 AP) 以特工 Move 數值進行移動，過程中任何部位均不可進入敵方 1" 控制範圍。
Dash 衝刺 (1 AP) 固定移動 3 吋，不能攀爬，用於延伸移動距離。
Charge 衝鋒 (1 AP) 以 Move + 2 吋移動，必須於敵方控制範圍內結束移動並展開近身。
Shoot 射擊 (1 AP) 宣告一把遠程武器，對有效目標展開遠程交火與防禦判定。
Fight 近戰搏鬥 (1 AP) 宣告一把近戰武器，雙方同時擲骰，輪流選擇打擊或招架。
Fall Back 撤退 (2 AP) 在被敵軍近身貼合時脫離戰鬥，結束時不得留在敵方控制範圍內。
Pass 跳過 戰略階段中選擇不打出策略，或輪到行動時略過。
Control Range 控制範圍 特工底盤周圍 1 吋且可見的近身威脅警戒區域。
Cover 掩護 防守方在地形 1 吋範圍內阻礙敵方視線，可免擲並保留 1 顆普通成功防禦骰。
Counteract 反制行動 特工全部待機後，對手啟動時可選一名交戰特工免費執行 1AP 行動（限移2"）。
Critical Hit / Success 爆擊成功 通常為擲出 6 點或符合 Lethal 條件之成功骰，可造成高額爆擊傷害。
